# Engage class colors

The class colors of the 36 characters you can recruit in Fire Emblem Engage's
base game, on one page: English name, internal id, and the four mask colors as
hex codes.

**https://dogethis.github.io/engage-class-colors/**

Find a character with the browser's find (Cmd+F or Ctrl+F). The hex codes are
plain text to select and copy. The button at the top right switches between
light and dark.

The page is one generated HTML file. The colors are the `MaskColor100`, `075`,
`050` and `025` values on each character's base row of the game's
`AssetTable.xml`.

Text is set in EB Garamond, used under the SIL Open Font License (see
`OFL.txt`). Fire Emblem Engage and its data belong to Nintendo and Intelligent
Systems. This is an unofficial fan reference.
